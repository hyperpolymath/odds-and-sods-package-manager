== What is OPSM?

OPSM is the **first universal package manager** that combines:

1. **101 Registry Adapters** - npm, Hex, Crates, PyPI, RubyGems, Go, Pub, Hackage, NuGet, Maven, and 91 more ecosystems
2. **Post-Quantum Cryptography** - Hybrid Ed25519+Dilithium5 signatures, Kyber-1024 KEM, SPHINCS+ (Rust NIF)
3. **SLSA Level 3 Compliance** - Provenance generation, signature verification, policy enforcement
4. **PubGrub Dependency Resolver** - Semver, PEP 440, Go MVS support with ETS caching
5. **Trust Pipeline** - 5-microservice verification (claim-forge, checky-monkey, palimpsest-license, oikos, cicd-hyper-a)
6. **Container Security** - 4 Rust services (svalinn, selur, vordr, cerro-torre)
7. **Sustainability Scoring** - Oikos-based real package-level analysis integrated into resolver
8. **Formal Verification** - Proven library (SSRF/DoS prevention via property-based testing)
9. **Federation-First** - Event propagation, distributed architecture, cross-registry search
10. **Human-Assisted Discovery** - 3 agentic agents for obscure language packages

**Unlike npm/cargo/pip:** OPSM works across languages and verifies every package through a trust pipeline.

**Unlike Nix/Guix:** OPSM focuses on language ecosystems, not OS-level reproducibility.

== Quick Start

=== Search for Packages

[source,bash]
----
# Search across all registries
opsm search express

# Search specific registry
opsm search phoenix --registry hex
opsm search tokio --registry crates
----

=== Install Packages

[source,bash]
----
# Install from any registry
opsm install express --registry npm
opsm install phoenix --registry hex
opsm install tokio --registry crates

# Install with version constraint
opsm install express@^4.18.0 --registry npm

# Install from Git
opsm install https://github.com/owner/repo.git --registry git
----

=== Dependency Resolution

[source,bash]
----
# View dependencies
opsm depends express --registry npm

# View reverse dependencies
opsm rdepends mime-types --registry npm

# Install with full dependency tree
opsm install express --registry npm
# Resolves: express → accepts → mime-types → mime-db
# Creates opsm.lock with full tree
----

=== Publish Packages

[source,bash]
----
# Publish through trust pipeline
opsm publish ./my-package

# Trust pipeline stages:
# 1. claim-forge: Generate attestation
# 2. checky-monkey: Verify package integrity
# 3. palimpsest-license: Check license compatibility
# 4. oikos: Score sustainability (8 dimensions)
# 5. cicd-hyper-a: Publish to registry + federation

# View published package
opsm show my-package --registry <registry>
----

=== Audit Packages

[source,bash]
----
# Audit sustainability + licenses
opsm audit https://github.com/owner/repo

# Returns:
# - Sustainability score (0-100 across 8 dimensions)
# - License analysis
# - Security advisories (if any)
----

=== Registry Adapters (101 Ecosystems)

Each registry adapter implements a common interface:

[source,elixir]
----
defmodule Opsm.Registries.RegistryAdapter do
  @callback search(query :: String.t()) ::
    {:ok, [package()]} | {:error, term()}

  @callback fetch_package(name :: String.t(), version :: String.t()) ::
    {:ok, ResolvedPackage.t()} | {:error, term()}

  @callback fetch_dependencies(name :: String.t(), version :: String.t()) ::
    {:ok, [dependency()]} | {:error, term()}
end
----

**Adapter Types:**
1. **HTTP API** - npm, Hex, Crates, PyPI, Nimble (direct registry APIs)
2. **Git-based** - Idris2 (curated list), generic Git (any repository)
3. **Agentic** - HAR queue system with 3 discovery agents

=== Trust Pipeline (5 Microservices)

Every `opsm publish` goes through 5 verification stages:

[cols="1,2,2"]
|===
| Service | Purpose | Verification

| **claim-forge**
| Attestation generation
| Creates SLSA-style attestations with package metadata

| **checky-monkey**
| Package verification
| Async integrity checks (60s timeout, 5s polling)

| **palimpsest-license**
| License analysis
| Detects conflicts, validates compatibility

| **oikos**
| Sustainability scoring
| 8-dimensional scoring (security, maintenance, docs, tests, etc.)

| **cicd-hyper-a**
| Publication + federation
| Publishes to registry, propagates events to mirrors
|===

**Error Severity:**
- **HARD_FAIL** - License conflicts, signature failures (blocks publish)
- **SOFT_FAIL** - Service timeouts, network errors (logs warning, continues)
- **WARNING** - Low sustainability scores, optional checks

=== HAR (Human-Assisted Registry)

For obscure languages without centralized registries, OPSM uses **3 agentic discovery agents:**

1. **github-search.sh** (Bash) - GitHub API search for language-specific packages
2. **web-scraper.jl** (Julia) - DuckDuckGo search + HTML parsing for package metadata
3. **mirror-finder.sh** (Bash) - Software Heritage, Wayback Machine, Debian/Fedora archives

**Queue Location:** `/tmp/opsm-har-ingest/`

**Workflow:**
[source]
----
1. opsm install idris2-json --registry agentic
2. Task queued: /tmp/opsm-har-ingest/idris2-json.task.json
3. Agents poll queue, search for package
4. Results posted back: /tmp/opsm-har-ingest/idris2-json.result.json
5. OPSM reads result, installs package
----

**Deployment:** See link:scripts/har-agents/README.md[HAR Agent Documentation]

=== Verified Library (Security Guarantees)

OPSM uses property-based testing to provide formal security guarantees:

**Verified.Url** - SSRF Prevention
[source,elixir]
----
# Blocks localhost and private IPs
Verified.Url.validate("http://localhost:8080")
# => {:error, :private_ip}

Verified.Url.validate("http://127.0.0.1/admin")
# => {:error, :private_ip}

Verified.Url.validate("https://registry.npmjs.org/express")
# => {:ok, %URI{...}}
----

**Verified.Json** - DoS Prevention
[source,elixir]
----
# Enforces depth limit (20 levels) and size limit (10MB)
Verified.Json.decode(deeply_nested_json)
# => {:error, :depth_exceeded}

Verified.Json.decode(huge_json)
# => {:error, :size_exceeded}
----

**Verified.Result** - Railway-Oriented Programming
[source,elixir]
----
# Explicit error handling, satisfies monad laws
{:ok, data}
|> Result.map(&transform/1)
|> Result.and_then(&process/1)
|> Result.unwrap_or(default_value)
----

**Testing:** 40 property-based tests verify security properties (see link:test/opsm/verified_test.exs[verified_test.exs])
