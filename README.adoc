A *federated, multi-language package manager* with **formal verification**, a **multi-dimensional trust pipeline**, **automated ecosystem health monitoring**, and **agentic package discovery** for obscure languages.

== Overview
{project-name} wires the **hyperpolymath ecosystem** into a single user-facing CLI and federation hub.
Built with **ReScript** (compiled to {rescript-runtime}) and **Idris 2** ({idris-core}), it supports:

* **Centralized registries**: npm, Crates.io, Hex, PyPI, Nimble
* **Git-based ecosystems**: Idris2, any git repository
* **Agentic discovery**: Legacy sites, university repos, unmaintained projects (via HAR)

=== Key Features
- **Formal verification**: Crash-free operations with `proven` (Idris 2)
- **Trust pipeline**: `checky-monkey`, `claim-forge`, `palimpsest-license`, `oikos`
- **Federation**: Mirrors to GitHub/GitLab/Codeberg/Radicle/IPFS
- **Bot ecosystem**: `rhodibot`, `seambot`, `echidnabot`, `robot-repo-automaton`

== Quick Start
[source,bash]
----
# Build ReScript
deno task build

# Run directly
deno task {project-name} status

# Install globally
deno install --allow-read --allow-env --allow-net --allow-run -n {project-name} cli/Main.res.js

# Usage
{project-name} publish ./my-package
{project-name} audit @scope/package
{project-name} status
----

== Configuration
Config search order:
1. `$OPSM_CONFIG`
2. `./{project-name}.toml`
3. `~/.config/{project-name}/{project-name}.toml`

Example `{project-name}.toml`:
[source,toml]
----
[http]
timeout_ms = 3000
retries = 2
backoff_ms = 200

[claim_forge]
base_url = "http://127.0.0.1:7001"

[checky_monkey]
base_url = "http://127.0.0.1:7002"
----

== Verification
Uses `proven` for mathematically verified operations:
- `SafeUrl`: URL validation
- `SafeJson`: Safe JSON parsing
- `Result`: Crash-free error handling
