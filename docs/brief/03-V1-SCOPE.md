# V1 scope

## In scope
- discover
- compare
- plan
- install
- configure
- essential environment wiring
- essential local service enablement
- essential secrets handling
- trust and reversibility as cross-cutting concerns
- federated sources
- local, media, device/peripheral, and narrow cloud targets
- target creation for local software-defined targets where practical

## Out of scope for core v1
- full organisational identity integration
- enterprise policy/directory integration
- remote fleet management
- general remote-machine orchestration
- full cloud control-plane management
- full hypervisor orchestration
- full organisational policy/governance layer

## Target creation in v1
Include:
- create local containers
- create toolbox/distrobox environments
- possibly simple local VMs where practical
- prepare USB/disk images where practical

Defer:
- physical hardware provisioning
- remote server provisioning as a broad category
- cloud lifecycle management
