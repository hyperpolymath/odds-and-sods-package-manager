= OPM Architecture
:revdate: 2026-01-18

== Overview

OPM is a federated package manager that composes existing hyperpolymath services into a single CLI and registry hub.

== Current state

- CLI wiring stubs implemented (HTTP + config)
- Registry schemas + examples present
- IMP draft documentation + schema present

Next: formalize service contracts and wire live endpoints.

== Event types

[source,yaml]
----
communication:
  event_types:
    - package-published
    - security-advisory
    - deprecation-notice
    - maintainer-change
    - compatibility-break

  propagation:
    security-advisory:
      priority: critical
      immediate: true
      notify_all_dependents: true
----

== Integration layers

- Verification: proven (Idris2)
- Manifests: nickel-config-reporter + hybrid-automation-router + protocol-squisher + scaffoldia
- Trust pipeline: checky-monkey + claim-forge + palimpsest-license + oikos
- Registry: cicd-hyper-a + http-capability-gateway
- Federation: git-private-farm + Radicle + IPFS
- Bots: rhodibot, seambot, echidnabot, robot-repo-automaton

== CLI orchestration

The `opsm` CLI coordinates publish/audit/status calls into the trust pipeline and registry.
