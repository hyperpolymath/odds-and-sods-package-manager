== _pathroot Integration

OPSM uses `_pathroot` to resolve install destinations and environment policies:

* system paths
* per‑project paths
* user sandbox paths

== Policy Hooks

* Allow/deny language families (e.g., ¬python)
* Force container for untrusted sources
* Auto‑suggest alternatives
