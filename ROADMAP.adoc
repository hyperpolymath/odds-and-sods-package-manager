== Overview

== Critical Chain (Priority Path)

OPSM’s highest‑impact milestone path is:

1. **Package‑managerless languages** (hardest‑to‑install first)
2. **Rogue repos / extrepos** (GitHub/GitLab/Bitbucket that lack manifests)
3. **OS‑package fallback** (when apt/dnf/pacman/rpm‑ostree fail)

This path is additive and does not replace the rest of the roadmap.

=== Example (Smart Install)

[source,bash]
----
opsm install [rpm-ostree: gnat ada ats2 v forth factor ldc zig idris2 ghc]   [toolbox: janus arrow paxos kraft raft swi-prolog datalog logtalk qml ocaml j lisp lfe rust gcc gcc-c++]
----

Expected behavior:

* Classify packages by backend
* Offer substitutes (e.g., gforth when "forth" missing)
* Dry‑run plan with conflicts and policy warnings
* Reversible apply if approved


OPSM's roadmap progresses through four major phases:

[source]
----
v1.0.0 ✅ (Released Jan 23, 2026)  → Stable Core
v1.0.1 ✅ (Released Feb 5, 2026)   → Phase 1 Cryptographic Integration
v1.1.0 ⏳ (Q1 2026 - 5 weeks)      → Production Hardening
v1.5.0 📋 (Q2 2026 - 8 weeks)      → Enhanced Trust & Security
v2.0.0 🎯 (Q3 2026 - 18 weeks)     → Scale & Intelligence
v3.0.0–v12.0 📈 (2026–2029)        → Reliability, Safety, and Federation at Scale
v13.0+ 🔮 (2030+)                  → Long-horizon vision
----

**Total Timeline to v2.0:** 6 months from v1.0 release

== Community Painpoints We Are Assimilating

The roadmap from v2.0 through v12.0 explicitly targets the most common pain points seen across
other package managers. This is not theoretical: each item below is mapped to concrete milestones.

* **Supply‑chain abuse** (typosquatting, malicious packages, dependency confusion)
* **Resolver instability** (backtracking loops, slow/opaque conflict errors)
* **Lifecycle script risk** (arbitrary install-time code execution)
* **Outages and flakey registries** (downtime, rate limits, inconsistent mirrors)
* **Proxy/TLS pain** (corporate MITM, custom certs, locked-down networks)
* **Lockfile drift** (non‑reproducible builds, cross‑platform differences)
* **Monorepo + multi‑lang friction** (inconsistent semantics across ecosystems)
* **Governance ambiguity** (who can publish, how to revoke, how to recover)

Each major version below lists explicit remedies for these concerns.
